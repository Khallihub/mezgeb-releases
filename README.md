# Mezgeb releases

Android builds of **Mezgeb (መዝገብ)**, the inventory and point-of-sale app for shops in Ethiopia.

Download the latest version from the [Releases](https://github.com/Khallihub/mezgeb-releases/releases/latest) page, or directly:

https://github.com/Khallihub/mezgeb-releases/releases/latest/download/mezgeb.apk

Each release lists the version and the APK's SHA-256 so you can check the file.

This repository holds release files only. The app's source code is private.
